# OUR PLANET 🌍 — Our little universe

Интерактивный 3D-мир к трём месяцам вместе: маленькая планета с пятью местами, домом с письмом, секретами и финальной сценой.
Работает в браузере (iPhone Safari, Chrome, Firefox, десктоп), без сервера и базы данных.

---

## Быстрый старт

### Вариант 1 — просто открыть
Дважды щёлкните `index.html`. Сайт откроется в браузере.
Нужен интернет: библиотеки (Three.js, GSAP, Lucide) и шрифты грузятся с CDN.

> Если свой музыкальный файл не играет при открытии через `file://` — используйте вариант 2 или GitHub Pages.

### Вариант 2 — локальный сервер (рекомендуется для проверки)
В папке проекта:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.
Чтобы посмотреть с телефона в той же Wi‑Fi сети: `http://IP-вашего-компьютера:8000`.

Полезно при проверке:
- `?skip=1` — пропустить вступление;
- `?q=low` / `?q=high` — принудительно лёгкое / полное качество.

## Как поменять тексты

**Все тексты — в одном файле: `js/content.js`.** Логику трогать не нужно.

| Что | Где в `content.js` |
|---|---|
| Название, подзаголовок | `project` |
| Её имя / обращение, ваша подпись | `names.her`, `names.him` (в любом тексте можно писать `{her}` и `{him}`) |
| Даты, счётчик «вместе уже N дней» | `dates.start` (ГГГГ-ММ-ДД), `dates.label` |
| Фразы вступления, кнопка входа | `intro` |
| Комплименты маяка | `locations.ocean.compliments` |
| Сообщения деревьев | `locations.forest.messages` |
| Сообщение гор | `locations.mountains.message` |
| Причины любви (цветы) | `locations.garden.reasons` — сколько строк, столько цветов (минимум 15) |
| Надпись башни и мечты | `locations.city.towerMessage`, `locations.city.dreams` |
| **Письмо** | `home.letter` — замените абзацы в квадратных скобках своими словами |
| Секреты | `secrets` |
| Финальная сцена | `finale` |

Правила: текст внутри кавычек `"..."`, между пунктами списка — запятая. Если внутри текста нужны кавычки — используйте «ёлочки».

⚠️ Перед тем как отправлять ссылку, обязательно замените заготовку письма (`home.letter.paragraphs`). Абзацы в квадратных скобках показываются серым — так видно, что это ещё заготовка.

## Музыка

1. Положите свой файл (mp3 / m4a) в `assets/audio/`, например `assets/audio/music.mp3`.
2. В `content.js` укажите путь: `music.file: "assets/audio/music.mp3"` и громкость `music.volume` (0…1).

Если файла нет, играет встроенная мягкая музыка — она генерируется прямо в браузере и не нарушает ничьих авторских прав.
Звуки интерфейса (открытие мест, письма, секретов) тоже синтезируются, файлы для них не нужны.
Музыка никогда не включается сама — только по кнопке 🔈.

## Фотографии (по желанию)

1. Положите фото в `assets/images/` (лучше квадратные, до ~1500 px, jpg).
2. В `content.js` добавьте их в `photos`:
   ```js
   photos: [
     { src: "assets/images/photo1.jpg", caption: "мы" },
     { src: "assets/images/photo2.jpg", caption: "наш вечер" }
   ]
   ```
Они появятся в письме как полароиды.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (можно приватный при платном аккаунте; для бесплатного — публичный).
2. Загрузите **содержимое** папки `our-planet` в корень репозитория (так, чтобы `index.html` лежал в корне).
   Через сайт: *Add file → Upload files* → перетащите все файлы и папки → *Commit changes*.
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch*, ветка `main`, папка `/ (root)` → *Save*.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Все пути в проекте относительные, сервер не нужен — всё загрузится корректно.

💡 На iPhone: откройте ссылку в Safari → «Поделиться» → «На экран Домой». Сайт откроется во весь экран, как приложение.

## Что есть на планете

- **Вступление** — из звёздной пыли рождается планета, появляются фразы и кнопка «Войти в наш мир ❤️».
- **Океан нежности** — бирюзовая вода, светящиеся волны, лотосы, маяк → листаемые карточки комплиментов.
- **Лес улыбок** — разноцветные «деревья улыбок», светлячки, грибы, домики, лесные духи → сообщения.
- **Горы приключений** — вершины со снегом, облака, водопад, мост между островами → флаг на вершине открывает послание.
- **Сад любви** — фонтан, летающие лепестки, большие цветы: каждый цветок — своя причина, прогресс сохраняется.
- **Город мечтаний** — вечерние огни, река с мостами, башня с часами (показывают реальное время) → мечты.
- **Наш дом** — остров с домиком, террасой, фонарями и озером → дверь открывается, письмо в конверте с печатью.
- **Секреты (4)** — загаданная звезда в небе, спрятанное сердце, бутылка с посланием, маленькая луна на орбите.
- **Финал** — после открытия всех пяти мест появляется кнопка «Посмотреть нашу историю».

Письмо доступно сразу, без прохождения: кнопка «Вернуться домой».

## Управление

- Вращение — палец / мышь, приближение — щипок / колесо.
- Нажатие на подпись места или на саму область планеты — перелёт к месту.
- «Вся планета» — вернуться к общему виду. Отдалить жестом в месте — тоже возвращает к общему виду.

## Производительность

- На слабых устройствах автоматически включается лёгкий режим; вручную — в настройках (⚙︎) «Лёгкий режим».
- Если кадры долго проседают, разрешение рендера снижается автоматически.
- Когда вкладка неактивна, анимация и звук ставятся на паузу.
- Прогресс (открытые места, цветы, секреты) хранится в браузере; сбросить — в настройках.
